# X-Partner — сайт

Лендінг + легка адмінка для бізнесу з оренди авто та працевлаштування водіїв таксі. Двомовний (PL / UA).

## Технології

- Next.js (React) + TypeScript + Tailwind CSS
- SQLite (файл бази) через Prisma ORM
- Фото зберігаються у `public/uploads`

## Запуск локально

```bash
npm install
npm run db:migrate   # створити/оновити таблиці бази
npm run db:seed      # заповнити базу початковим контентом (тільки якщо база порожня)
npm run dev
```

Сайт відкриється на http://localhost:3000 (автоматично перенаправить на `/pl`).

Адмінка: http://localhost:3000/admin/login — пароль береться зі змінної `ADMIN_PASSWORD` у файлі `.env` (за замовчуванням `change-me-please`). **Одразу після першого входу змініть пароль** у розділі «Налаштування» адмінки.

## Структура вмісту

- `/admin/cars` — додавання/редагування/видалення авто, фото, ціни, статус «доступне».
- `/admin/leads` — заявки з форм сайту (запит про авто, заявка водія, контактна форма).
- `/admin/pages` — редагування тексту сторінок «Про нас», «Політика конфіденційності», вступ на сторінці «Контакти».
- `/admin/settings` — телефон, e-mail, адреса (показуються у футері й на сторінці контактів), зміна пароля адмінки.

## Змінні середовища (`.env`)

```
DATABASE_URL="file:../data/app.db"
ADMIN_PASSWORD="пароль-для-першого-входу"   # використовується лише при npm run db:seed
SESSION_SECRET="довгий-випадковий-рядок"     # для підпису cookie-сесії адмінки
```

`ADMIN_PASSWORD` впливає тільки на *seed* (перше створення бази). Після цього пароль можна міняти лише через адмінку.

## Деплой (продакшн)

Проєкт зберігає дані у файловій базі SQLite (`data/app.db`) і локальних файлах (`public/uploads`) — тому потрібен хостинг зі **сталим диском** (persistent disk), а не безсерверний (Vercel/Netlify тут не підійдуть без додаткових змін).

Рекомендація: [Railway.app](https://railway.app) — підключаєте GitHub-репозиторій, додаєте Volume (диск) змонтований у `/app/data` і `/app/public/uploads`, задаєте змінні середовища (`DATABASE_URL`, `ADMIN_PASSWORD`, `SESSION_SECRET` — новий, довгий, секретний рядок), деплой відбувається автоматично при пуші в гілку.

Перед першим запуском на проді виконати одноразово: `npm run db:migrate && npm run db:seed`.

## Прив'язка домену x-partner.pl (GoDaddy)

1. У Railway (або іншому хостингу) отримайте CNAME/A-запис для вашого домену.
2. У панелі GoDaddy → DNS Management для x-partner.pl додайте відповідний запис (CNAME для `www`, A-запис для кореневого домену — точні значення дасть хостинг після підключення домену в його інтерфейсі).
3. Зачекайте до 24 годин на поширення DNS.

## Пошта kontakt@x-partner.pl (Zoho Mail, безкоштовно)

1. Зареєструватися на zoho.com/mail → Free plan → вказати домен x-partner.pl.
2. Zoho дасть список DNS-записів (MX, TXT для верифікації, SPF). Додати їх у GoDaddy DNS Management.
3. Після верифікації створити поштову скриньку, наприклад kontakt@x-partner.pl.
4. Вписати цю адресу в `/admin/settings`, щоб вона показувалась на сайті.
